# 会計のテスト用

青山学院大学 会計学の授業内テスト対策ページです。

## ページ構成

- `index.html`: まとめページ
- `test1.html`: 第1回テスト対策。第2回から第6回、財務会計1から5。
- `test2.html`: 第2回テスト対策。第7回から第10回。要点整理、図解、予想問題。
- `test3.html`: 第3回テスト対策。第11回から第14回。

## 作成方針

第1回テスト対策は、講義範囲と実際に出た問題、テスト後の解説音声をもとに整理しています。

テスト対策ページでは、次の内容を整理します。

- 講義範囲の要点整理
- 用語カード
- 図解
- 記述式の予想問題
- 実際に出た問題のログ

第2回テスト対策は、図から読み取る問題と「なぜ」を説明する問題を重点的に作っています。

第3回テスト対策は、第11回から第14回の講義資料を反映しています。CVP・BEPの計算演習、資料の数値から答える問題、仕組みの理由を説明する問題を収録しています。

## 開き方

`index.html` をブラウザで開いてください。

GitHub Pagesで公開する場合は、このリポジトリのPages設定で `main` ブランチのrootを選ぶと表示できます。
